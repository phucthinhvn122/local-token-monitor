# Contributing

Thank you for helping improve Local Token Monitor.

1. Open an issue describing the provider version, operating system, and expected behavior.
2. Never attach real session logs. Reduce records to synthetic fixtures containing only safe metadata and token fields.
3. Run `npm test`, `npm run lint`, and `npm run build`.
4. Keep provider format logic inside its adapter and add a parser version plus fixtures.
5. Preserve loopback-only defaults and do not add telemetry or remote requests.

Small, focused pull requests are easiest to review. By participating, you agree to the Code of Conduct.
