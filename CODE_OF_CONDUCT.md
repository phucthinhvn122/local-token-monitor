# Code of Conduct

We are committed to a welcoming, harassment-free project for everyone. Be respectful, assume good intent, give actionable technical feedback, and protect the privacy of other contributors.

Unacceptable behavior includes harassment, discriminatory language, publishing another person's private information, or sharing real prompts, credentials, or session data without explicit permission.

Project maintainers may remove, edit, or reject contributions and comments that violate these expectations. Report conduct concerns privately to the maintainers through the repository contact channel.
